# BlockHost Minecraft Hosting Site

A static free Minecraft server hosting website that works on GitHub Pages. It includes free server options, a builder, and status cards.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload these files to the repository root.
3. In `index.html`, change visible brand text if you want a different name.
4. In GitHub, go to `Settings > Pages` and choose `GitHub Actions`.

The included workflow publishes the site automatically whenever you push to `main`.

## Customize

- Edit plan names in `index.html`.
- Edit builder behavior in `script.js`.
- Edit colors and layout in `styles.css`.
